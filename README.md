# Portafolio de Sofía Luna

Portafolio único construido con Next.js 14 y TypeScript para presentar la trayectoria y proyectos de Sofía Luna.

## Scripts disponibles

- `npm run dev` – inicia el entorno de desarrollo en `http://localhost:3000`.
- `npm run build` – genera la versión de producción.
- `npm run start` – sirve la build de producción.
- `npm run lint` – ejecuta las reglas de linting.

## Estructura principal

- `app/` – páginas y layout principal.
- `components/` – componentes reutilizables de la interfaz.
- `lib/data.ts` – contenido estructurado para experiencias, proyectos e insights.
- `public/` – recursos estáticos como ilustraciones.

## Personalización

Actualiza el contenido en `lib/data.ts` y ajusta los estilos en los módulos CSS de cada componente para adaptar la estética o la narrativa a tus necesidades.
